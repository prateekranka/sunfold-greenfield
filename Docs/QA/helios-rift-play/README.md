## What it is

The playable Helios Rift (The Broken Ring) proof: data-driven RTS space map with sprite
Citizens, path-graph bridges, solar core capture, solar flares, minimap, smooth 60fps
zoom/pan camera. Built from `ThreeRuntime/src/helios-rift-proof.js` + `src/rts-maps/`.

## Why a Worker (not plain Pages)

The default Cloudflare Pages/Workers asset serving for this site delivered the JS bundle
with a download-triggering `Content-Disposition`/wrong MIME. `worker/index.js` forces the
correct `Content-Type` per extension and strips `Content-Disposition` — this is the fix
for the "opening the URL downloads a file" bug. `run_worker_first = true` in the assets
binding makes the worker run before the static asset handler.

## How to rebuild + redeploy

Requires Cloudflare auth (Cloudflare MCP in Cursor, or `CLOUDFLARE_API_TOKEN`):

```bash
# 1. Build the site folder (npm run build:labs → copies html/bundle/atlas into site/)
node Tools/citizens/build-helios-play-site.mjs

# 2. Full redeploy (build + assets upload + worker deploy)
#    via Cursor Cloudflare MCP: create assets-upload-session JWT, then
ASSETS_UPLOAD_JWT=<jwt> node Tools/citizens/deploy-helios-play.mjs
#    or with a token:
CLOUDFLARE_API_TOKEN=<token> ASSETS_UPLOAD_JWT=<jwt> node Tools/citizens/deploy-helios-play.mjs
```

`wrangler deploy --config Docs/QA/helios-rift-play/worker/wrangler.toml` also works when
the wrangler CLI is logged in (assets binding `directory = "../site"`).
